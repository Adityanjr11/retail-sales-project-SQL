# Retail Sales Data Pipeline

## Project Overview
This project builds an end-to-end data pipeline using the Online Retail dataset.

## Workflow
Excel Dataset → Python Ingestion → MySQL Raw Table → SQL Cleaning → Analysis Queries

## Tech Stack
- Python
- MySQL
- Pandas
- SQL (CTEs, Window Functions)

## Project Structure
data/
python/
sql/

## Key Features
- Data ingestion using Python
- Data cleaning using SQL
- Duplicate removal using ROW_NUMBER()
- Revenue calculations
